## 二、公共 API

### 2.1 Browse

```python
def browse(
    self,
    node_text: str = "Root",
    *,
    recursive: bool = True,
    max_depth: Optional[int] = None,
) -> Tuple[bool, Optional[dict]]:
    """枚举节点树。

    :param node_text: 起始 NodeId 字符串(默认 `"Root"` 即服务端根节点)
    :param recursive: True 递归到叶子;False 仅顶层
    :param max_depth: 递归深度上限(`None` = 无限制);防服务端巨大树爆栈
    :return: ``(成功, 嵌套 dict)``;嵌套 dict 结构::

            {nodeId_str: {
                "browse_name": str,
                "node_class": str,        # "Object"|"Variable"|"Method"|...
                "children": dict | None,  # recursive=False 时 None
            }}

    :raises ValueError: ``max_depth`` 为负
    """
```

### 2.2 订阅 — DataChange

```python
def subscribe_data_change(
    self,
    node_text: str,
    on_change: Callable[[Any, str, Optional[float]], None],
    *,
    sampling_interval_ms: int = 1000,
) -> Tuple[bool, Optional["OpcUaSubscription"]]:
    """订阅节点值变化。

    :param node_text: 节点 NodeId 字符串
    :param on_change: 回调签名 ``(value, node_id_str, source_timestamp)``;
        异常被捕获,记入 ``client.last_error``,**不杀订阅**
    :param sampling_interval_ms: 采样间隔(毫秒,默认 1000)
    :return: ``(成功, 订阅句柄)``;``False`` 时 ``None``
    """
```

### 2.3 订阅 — Event

```python
def subscribe_event(
    self,
    node_text: str,
    on_event: Callable[[dict, str, Optional[float]], None],
    *,
    event_filter: Optional[Any] = None,
) -> Tuple[bool, Optional["OpcUaSubscription"]]:
    """订阅事件。

    :param node_text: 节点 NodeId 字符串(必须 EventNotifier = SubscribeToEvents)
    :param on_event: 回调签名 ``(event_fields_dict, node_id_str, source_timestamp)``;
        event_fields_dict 由 ``asyncua`` 解析自服务端事件字段
    :param event_filter: 透传给 asyncua(可选过滤子句;None = 不过滤)
    """
```

### 2.4 订阅句柄

```python
class OpcUaSubscription:
    """订阅句柄(由 subscribe_* 返回)。

    唯一公开方法 ``unsubscribe()``,**幂等**,线程安全,失败返回 False
    (已断开 / 已取消);其他属性只读。
    """

    @property
    def node_id(self) -> str: ...          # 订阅的 NodeId 字符串

    @property
    def subscription_id(self) -> int: ...  # asyncua 内部 id,debug 用

    def unsubscribe(self) -> bool: ...
```

## 三、内部架构

### 3.1 模块结构

```
src/omniplc/opcua/client.py 增:

  - _OpcUaSubscription
    - 持有 asyncua Subscription + MonitoredItem(s) + on_change/on_event 回调
    - __exit__/close 时:asyncua 的 Subscription.delete() + MonitoredItem 取消
    - 引用计数防泄漏;同一节点可多次订阅(每次独立 handle)

  - OpcUaClient.subscribe_data_change(...)
    - 1. asyncua sync Client 的 uaclient.subscribe() 创建 Subscription
    - 2. monitored = Subscription.subscribe_data_change(nodes, handler, sampling_interval_ms)
    - 3. handler 内:把 asyncua DataChangeNotification 翻译成 (value, node_id_str, ts)
                    调 on_change(*args)
    - 4. 返回 (True, _OpcUaSubscription(...))

  - OpcUaClient.subscribe_event(...)
    - 类似;event handler 用 asyncua 的 EventHandler 钩子

  - OpcUaClient.browse(...)
    - 递归:从 Root 拉 children;每个 child 再拉 children
    - max_depth 边界检查;服务端属性(如 browse_name、node_class)一次拉取缓存
    - 失败/无权限的子节点 → 跳过 + 继续,不中断整树
```

### 3.2 锁内行为:`subscribe_*` 与 `unsubscribe` 必须在 BaseClient 锁内调用

- `BaseClient._lock` 持锁期间才创建/销毁订阅句柄(防止断开瞬间回调)
- 回调执行**不在**锁内(回调用户代码可能慢);订阅句柄的 unsubscribe 通过锁串行化

### 3.3 内部回调桥(asyncua 线程 → 用户回调)

```
asyncua internal thread          MainThread / aio loop
        │                                 ▲
        ▼                                 │
  DataChangeNotification ──► 翻译为 ──► on_change(value, node_id, ts)
                            (try/except: 异常 → client._set_error(...))
```

## 四、生命周期与重连

| 事件 | 行为 |
|---|---|
| `subscribe_*` 失败 | `(False, None)`,不上缓存,返回失败原因进 `last_error` |
| `subscribe_*` 成功 | 句柄入 `client._active_subscriptions`(dict[id → handle],用于断开时清理) |
| `disconnect()` / `_mark_disconnected()` | 清空 `_active_subscriptions`(每个 handle unsubscribe,删 asyncua 端) |
| `connect()` 重连 | **不**自动重订(简化生命周期);用户需重新 subscribe |
| 句柄 `unsubscribe()` | 幂等;从 `_active_subscriptions` 移除;服务端 MonitoredItem 取消 |

**文档明确**:断开后所有订阅失效;订阅是 transient 状态。

## 五、错误处理

| 场景 | 处理 |
|---|---|
| asyncua 会话失效 | `_translate_asyncua_error` → `OmniPLCInternalError` → `_execute` 路径 |
| 服务端拒绝订阅(资源/权限) | `subscribe_*` 返回 `(False, None)`,错误三件套(`DeviceError` 或 `ProtocolFrameError`) |
| 节点不存在 / NodeId 字符串无效 | `DeviceError` + 明确码(`last_error_code`) |
| 用户回调抛异常 | `try/except` 包裹,异常进 `last_error`(`category=UNKNOWN`),订阅**继续** |
| `browse` 子节点无权限 | 跳过该子节点,继续枚举其他;不中断整树 |
| `browse` 服务端响应超长 | 走已有传输层超时(继承 BaseClient.receive_timeout);不新增 |
| `unsubscribe` 时已断开 | 返回 `False`,无错误(静默幂等) |

## 六、aio 镜像

`AOpcUaClient` 五个新公共表面:

```python
@property
def _sync(self) -> OpcUaClient: ...   # 既有

async def browse(self, node_text="Root", *, recursive=True, max_depth=None)
    -> Tuple[bool, Optional[dict]]:
    return await self._run(lambda: self._sync.browse(...))

async def subscribe_data_change(self, node_text, on_change, *, sampling_interval_ms=1000)
    -> Tuple[bool, Optional[OpcUaSubscription]]:
    # 注意:on_change 来自调用方所在协程,实际触发在 asyncua 内部线程;
    # 回调内调度到 aio loop:call_soon_threadsafe(loop, on_change, ...)
    ...

async def subscribe_event(...): ...  # 同上

@property
def active_subscriptions(self) -> dict:  # 只读 property
    return self._sync._active_subscriptions
```

**回调桥**:`AOpcUaClient.subscribe_*` 包装回调函数,内部把 on_change 替换为:
```python
async_loop = asyncio.get_running_loop()  # 在 _run 内捕获
def _bridge(value, node_id, ts):
    try:
        async_loop.call_soon_threadsafe(on_change, value, node_id, ts)
    except Exception as exc:
        # 走同步 _set_error 路径
        self._sync._set_error(_describe(exc), ErrorCategory.UNKNOWN, None)
```

aio 镜像内省守卫(动态)自动覆盖 5 个新公开名;无需额外断言。

## 十一、风险与回退

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 订阅句柄泄漏(客户端断开未清) | 低 | 中 | `_active_subscriptions` 收口在 disconnect;句柄 `__del__` 兜底(降级 to warn) |
| asyncua DataChangeNotification 阻塞回调 | 低 | 中 | 文档明示:回调应快速返回;复杂处理建议丢进自己队列 |
| 回调用户异常未捕获 | 低 | 中 | `try/except` 包裹,异常进 last_error(category=UNKNOWN);订阅继续 |
| Browse 服务端巨大树爆栈 | 中 | 中 | max_depth 默认 None,但要求调用方显式设上限;docs + 错误消息都提 |
| aio 回调桥 跨线程竞态 | 低 | 中 | `call_soon_threadsafe` 是 asyncio 官方线程安全原语 |
| asyncua Server 测试 fixture 启动慢 | 中 | 低 | fixture 一次启,test session 复用 |

### 回退方案

- 公共 API 是**纯增量**;若全部作废只需删除 client.py 中 subscribe_*/browse/OpcUaSubscription,**零 breaking**
- `OpcUaSubscription` 类是顶层独立符号,单独删除即可
