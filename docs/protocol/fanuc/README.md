# FANUC FOCAS(fwlib32)帧面事实档案

> 用途:ctypes 直绑 `fwlib32.dll` 的依据档案(铁律:厂商头文件为权威)。
> 本档案只登记绑定用事实,全部以同目录 `fwlib32.h`(16043 行)为唯一主源,
> 行号即该文件自印行号;外部参考只作交叉不作依据。

## 0. 物料出处与授权口径(如实登记)

- 主源:`fwlib32.h`——FANUC「CNC/PMC Data Window Library for FOCAS」
  官方头文件,版权 2003-2017 FANUC(头文件 1~19 行自印);获取渠道为
  **社区打包仓库 strangesast/fwlib(GitHub)**,非 FANUC 官方 Development
  包渠道——内容与官方开发包头文件一致性**待与官方包核对**(拿到官方包后
  diff 一次),在此之前所有布局事实均以本仓库这份头文件文本为准。
- 交叉:`examples/ctypes/main.py`(同仓库,Python ctypes 连接参考)、
  cnblogs snail1502/p/18068966(连接流程/端口 8193 旁证)、
  inventcom.net fanuc-focas-library(型号覆盖面)。
- 授权口径:FOCAS1/2 版权归 FANUC,库与手册未经许可不得复制/单独分发;
  本档案只登记**接口事实**(签名/结构体/错误码)与指向性引用,DLL 运行库
  本体不入库,由部署侧自备(海康 SDK 同款纪律)。
- 型号覆盖面(inventcom 页):0i-A/B/C/D/F/PD/PF、15/150-B、15i/150i、
  16/18/21 及 160i/180i/210i 系、30i/31i/32i/35i-A/B、Power Mate i、
  Power Motion i。**FOCAS1** 用于除 FS300i/310i/320i 之外的 CNC,
  **FOCAS2** 用于 FS300i/310i/320i;可用功能随控制软件版本浮动。

## 1. 连接形态

- 走线:TCP/IP(机床内嵌以太网口/Fast Ethernet Board),端口 **8193**
  (本库构造缺省;机床侧「系统 → 内嵌 → 公共」配置 IP);
  HSSB 走线不实现(需 CNC 侧 HSSB 板,头文件 15114 行 `cnc_allclibhndl2`
  为 HSSB 版)。
- 连接 API(15117~15128 行「Ethernet connection」段):
  - `cnc_allclibhndl3(const char *ip, unsigned short port, long timeout,
    unsigned short *h)`(15122 行)——超时秒;成功 *h 为库句柄
  - `cnc_freelibhndl(unsigned short h)`(12239 行)
  - `cnc_settimeout(unsigned short h, long ms)`(15128 行)——**每连接**
    socket 超时,建连后可随时改
  - `cnc_rdcncid(unsigned short h, unsigned long *id4)`(11288 行)——
    读 CNC ID(4×u32),本库用作身份回显与连通性确认
- 调用约定:Windows 侧 `WINAPI` = windows.h 的 `__stdcall`(头文件
  32~42 行:非 Windows 分支把 FWLIBAPI/WINAPI 全部清空)→ ctypes 用
  **`WinDLL`**;Linux 侧为 `CDLL`(本库首批不绑,加载期显式报不支持)。
- 生命周期:头文件 15999~16004 行 `cnc_startupprocess/cnc_exitprocess/
  cnc_exitthread` 为 **Linux process and thread** 段专用,Windows 不需
  (ctypes 仓库示例亦仅在 .so 场景调用)——本库不绑。

## 3. 尺寸宏(44~80 行;**Ethernet 通用 DLL = 无系列宏构建**)

- 头文件按 `#if defined(FS15D/FS16WD/F22_TYPE*/ONO8D...)` 系列宏切换
  结构体布局与函数名重映射(如 16010~16032 行 ONO8D 块把 ODBPRO/ODBDY
  `#define` 成 *o8 变体)——均为**编译期选择**,对应系列限定构建的 DLL;
  1118/1426/3133 行条件证明 **Ethernet 路径(!HSSB_LIB)默认布局对
  FS30i/FS15i/FS0i-D 统一生效**。
- **本库绑定的取值**:系列宏全不定义 → `#else` 默认分支:
  `MAX_AXIS=32`、`MAX_SPINDLE=8`(48~54 行第一块;56~75 行第二块为
  `#if !defined` 死代码守卫)、`ALL_AXES=-1`、`ALL_SPINDLES=-1`。
- `#pragma pack(push, 4)`(255 行)至 `#pragma pack(pop)`(10518 行)
  ——**结构体区统一 4 字节对齐**,ctypes 全部 `_pack_=4`。
- 结论:**fwlib32.dll(Ethernet)是通用转发 DLL**,运行期按所连 CNC
  适配;不实现系列分支,系列限定构建(HSSB/专用 DLL)不支持。

## 4. 首批绑定结构体(逐字段;行号即 fwlib32.h)

**ODBSYS**(2850~2858 行,`#if !defined(FS15BD)` 默认分支;
`cnc_sysinfo(unsigned short, ODBSYS *)`,12140 行;总 18 字节):
`short addinfo; short max_axis; char cnc_type[2]; char mt_type[2];
char series[4]; char version[4]; char axes[2];`
(FS15BD 变体 2860~2868 行首两字段变 dummy+char[2],不绑)

**ODBDY2**(457~481 行;`cnc_rddynamic2(unsigned short, short, short,
ODBDY2 *)`,10574 行):
`short dummy; short axis; long alarm; long prgnum; long prgmnum;
long seqnum; long actf; long acts;` + `union { struct { long
absolute[MAX_AXIS]; long machine[MAX_AXIS]; long relative[MAX_AXIS];
long distance[MAX_AXIS]; } faxis; struct { long absolute; long machine;
long relative; long distance; } oaxis; } pos;`
→ 轴=0 只填 oaxis("In case of 1 axis");轴=ALL_AXES(-1) 填 faxis。
(ODBDY 431~455 行的 alarm/prgnum/prgmnum 是 **short**,与 ODBDY2 布局
不同——本库只绑 ODBDY2 防混用错位;ODBDY3M 数组硬编码 32 亦不绑)

**ODBST2**(2928~2942 行,**无条件编译**;`cnc_statinfo2(unsigned short,
ODBST2 *)`,12146 行;13 short = 26 字节):
`short hdck; tmmode; aut; run; motion; mstb; emergency; alarm; edit;
warning; o3dchk; ext_opt; restart;`
(ODBST 2884~2925 行有三种系列布局——本库直接用 ODBST2 规避系列差异)

**ODBCNCID**(`cnc_rdcncid(u16, unsigned long *)`,11288 行):
4×`unsigned long`(示例按 `"%08x"` ×4 连接为 machine id)。

## 5. 首批未绑(第二批候选)

- `cnc_rdprgnum`/`ODBPRO`(778~783 行,10894 行)——rddynamic2 已含
  程序号,细粒度读留第二批
- `cnc_rdaxisdata`/`ODBAXDT`(641~648 行 16B,10674 行)——轴数据选择器
- `cnc_actf`/`cnc_acts(2)`(10539/10585/10588 行)——rddynamic2 已含
  actf/acts
- PMC 族(c_pmc_*)/参数族(cnc_rdparam*)/诊断族——只读面第二批以后
- 写族一律不做(数采只读口径,与 MTConnect 同域)
