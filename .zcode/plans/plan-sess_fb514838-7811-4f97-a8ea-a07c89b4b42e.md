## 二、继承设计要点(模板方法模式)

- `BaseClient` 收口全部公共逻辑:锁、重连、重试、last_error、类型化读写。类型化方法只写一次:`read_float(addr)` → `self._read(addr, DataType.FLOAT)`;子类只实现两个抽象原语 + 地址解析,杜绝重复实现。
- `ModbusBaseClient` 中间层封装"寄存器级"公共性;三个走线子类只负责组帧差异(MBAP vs CRC16)与传输挂载。
- 三菱 MC:TCP/UDP 两子类共享帧编解码;帧层内部按 3E/4E(QnA 兼容)与 1E(A 兼容)拆两个 codec 模块,1E 帧无网络号/PC 号前缀字段、软元件码表不同,架构文档单列帧型差异表。
- `BaseTransport` 抽象 `connect/close/send/recv`,协议层零感知走线。
- 异步侧组合同步实例(持有 `_sync`),继承镜像同名方法,协议逻辑仅一份。

## 三、线程安全设计(明确写入架构文档)

1. **单锁模型**:每个 client 一把 `threading.RLock`,保护连接状态、请求/响应事务、last_error;`connected`/`last_error` 返回加锁快照。
2. **事务粒度持锁**:一次读/写 = 锁内完成(必要时重连→组帧→send→recv→校验),保证帧不被 interleaving,跨线程共用同一 client 安全。
3. **文档化取舍**:同 client 并发调用被串行化(保证正确性而非并行吞吐);高并发开多 client(连接池留 v1.x)。
4. **重试语义在锁内**:读按 `retries` 重试;写默认 0 次(防重复写入),可显式开。
5. **Transport 非线程安全**,仅由 client 持锁调用;异步侧 `ThreadPoolExecutor(max_workers=1)` 串行化 + 同一把 RLock,双保险且保序。

- 所有类/方法/函数参数与返回值 100% PEP 484 注解;文件头 `from __future__ import annotations`;3.7 用 `typing.Tuple/List/Optional/Union`。
- 返回类型精确到方法:

```python
class BaseClient(ABC):
    def connect(self) -> bool: ...
    def disconnect(self) -> bool: ...
    @property
    def connected(self) -> bool: ...
    @property
    def last_error(self) -> Optional[str]: ...
    @property
    def receive_timeout(self) -> float: ...
    @receive_timeout.setter
    def receive_timeout(self, seconds: float) -> None: ...
    def __enter__(self: _C) -> _C: ...          # _C = TypeVar("_C", bound="BaseClient")
    def __exit__(self, exc_type: Optional[Type[BaseException]], exc_val: Optional[BaseException], exc_tb: Optional[TracebackType]) -> None: ...

    def read(self, address: str, data_type: str) -> Tuple[bool, Optional[PrimitiveValue]]: ...
    def write(self, address: str, data_type: str, value: PrimitiveValue) -> bool: ...
    def read_many(self, addresses: Sequence[str], data_type: str) -> List[Tuple[bool, Optional[PrimitiveValue]]]: ...

    def read_bool(self, address: str) -> Tuple[bool, Optional[bool]]: ...
    def read_short(self, address: str) -> Tuple[bool, Optional[int]]: ...
    def read_ushort(self, address: str) -> Tuple[bool, Optional[int]]: ...
    def read_int(self, address: str) -> Tuple[bool, Optional[int]]: ...
    def read_uint(self, address: str) -> Tuple[bool, Optional[int]]: ...
    def read_long(self, address: str) -> Tuple[bool, Optional[int]]: ...
    def read_ulong(self, address: str) -> Tuple[bool, Optional[int]]: ...
    def read_float(self, address: str) -> Tuple[bool, Optional[float]]: ...
    def read_double(self, address: str) -> Tuple[bool, Optional[float]]: ...
    def read_string(self, address: str, length: int = 32, encoding: str = "ascii") -> Tuple[bool, Optional[str]]: ...
    # write_* 同型,第二参数为对应值类型,返回 bool
```

## 五、API 速览(命名/错误风格沿用已确认结论)

```python
client = ModbusTcpClient(ip_address="192.168.0.10", port=502, station=1)
client.receive_timeout = 3.0
ok, val = client.read_float("hr100")       # (bool, Optional[float])
ok = client.write_float("hr100", 3.14)     # bool
print(client.last_error)
client.disconnect()
with ModbusTcpClient("192.168.0.10", 502, 1) as c: ...
rtu = ModbusRtuClient(station=1); rtu.configure_serial(port_name="COM3", baud_rate=9600)
mc  = MelsecMcTcpClient(ip_address="192.168.3.39", port=2000, frame="3E")   # "3E"|"4E"|"1E"
mc_a = MelsecMcUdpClient(ip_address="192.168.3.40", port=2000, frame="1E")  # A 系列走 UDP
fins = OmronFinsUdpClient(ip_address="192.168.250.1", port=9600)
```

错误风格:读 `(bool, value)`、写 `bool`,无自定义异常,`last_error` 记录最近失败详情。类名 `{品牌}{协议}{Tcp|Udp}Client`、异步加 A 前缀、`ip_address/port/station` 参数名、timeout 走 property——按 pyhsl 规范。
