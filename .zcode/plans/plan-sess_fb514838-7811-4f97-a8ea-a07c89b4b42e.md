# v0.8 OPC-UA 驱动:封装 asyncua==1.1.5(读写)

## 决策结论
- **Modbus:维持自研**(v0.2 已完成,协议简单 + pymodbus 无 py37 版本 + 错误契约统一,architecture.md §8 已记录,本次不动)。
- **OPC-UA:封装成熟库**——协议是完整规范栈(二进制编码/订阅/X.509 安全栈),自研数月且加密做错即事故;python-opcua 2022 年官方弃用;**asyncua==1.1.5** 是最后支持 py3.7 的版本(requires_python 空 + 依赖带 importlib-metadata<3.8 标记,已核实)。
- 首版只做 NodeId 读写;订阅/浏览不符合 BaseClient 拉模式,留后续。

## 实现

### 1. pyproject.toml
- 新增 extra:`opcua = ["asyncua==1.1.5"]`(dev extra 同步加入,供静态检查解析;若 32 位 py3.7 装 cryptography 失败则回退:dev 不装,测试全用假会话,mypy/ty 加 asyncua 忽略)。
- `[tool.mypy]` overrides 的 module 列表加 `asyncua`、`asyncua.sync`。

### 2. 新包 src/omniplc/opcua/(与 modbus 平级,协议标准非品牌)
- **address.py**:`parse_opcua_nodeid(text)` —— 正则校验四类 NodeId(`ns=2;s=Tag` / `i=100` / `b=base64` / `g=guid`,ns 可省略默认 0),不依赖 asyncua;非法抛 ValueError。返回轻量 NamedTuple `OpcUaNodeId(namespace, identifier, id_type)`。
- **client.py**:
  - `_OpcUaSession(BaseTransport)`:会话适配为传输外形(`_MxComLink` 先例)——connect() 惰性 `import asyncua.sync` → `sync.Client(endpoint, timeout)` → `connect()`;close() → `disconnect()`;send/recv 不可用(会话型无字节流)。
  - `OpcUaClient(BaseClient)`:构造参数 `endpoint="opc.tcp://192.168.0.10:4840"`(默认端口 4840;校验 opc.tcp:// 前缀);`_read/_write` = NodeId 解析 → `get_node().read_value()/write_value(value, variant_type)`;DataType → `ua.VariantType` 映射惰性构建(BOOL→Boolean,SHORT→Int16 … DOUBLE→Double,STRING→String);UaError(Bad 状态码)→ `DeviceError(code=StatusCode)` 不断线,ConnectionError → 惰性重连;asyncua 一律方法内延迟导入,核心导入零依赖。
  - v1 无安全配置(匿名/NoSecurity),docstring 注明。
- **__init__.py**:导出 `OpcUaClient`、`OpcUaNodeId`、`parse_opcua_nodeid`。

### 3. 导出与异步镜像
- `omniplc/__init__.py`:__all__ 加 `OpcUaClient`(33 项)+ 模块 docstring 提及 OPC-UA。
- `omniplc/aio/__init__.py`:`AOpcUaClient(ABaseClient)` —— 与其他 A 类统一走单线程 executor 包装(asyncua.sync 内部本就有线程 loop,双层串行保序)。

### 4. 测试 tests/unit/test_opcua_client.py(无需 asyncua,假会话注入)
- NodeId 解析:四类合法形式 + ns 省略 + 非法样本。
- 假会话(FakeNode 记录 read_value/write_value 调用 + FakeUaError 带 code):读 BOOL/SHORT/FLOAT/STRING 往返;写各类型断言传参;`_to_variant_type` 打桩记录 DataType。
- Bad 状态码 → DeviceError 不断线;连接错误 → (False,None) + 标记断开 + 惰性重连。
- 参数错误 ValueError;异步镜像往返。
