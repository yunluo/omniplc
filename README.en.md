# omniplc

#### Description
omniplc —— 一个面向多品牌、多协议 PLC 的 Python 统一通信库。一次编写，即可通过一致的 API 对接西门子、三菱、欧姆龙、罗克韦尔等 PLC，支持 Modbus、S7、MC、FINS、EtherNet/IP 等协议
